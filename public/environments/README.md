# Environment maps

The local 1K HDR maps in this folder are bundled by `@react-three/drei` for its Environment presets and are served locally by this viewer so the scene does not depend on the preset CDN at runtime.

Files: `studio_small_03_1k.hdr`, `lebombo_1k.hdr`, `potsdamer_platz_1k.hdr`, `venice_sunset_1k.hdr`.

The original HDRI Haven / Poly Haven assets are CC0. See https://polyhaven.com/license and the pinned Drei asset bundle at https://github.com/pmndrs/drei-assets/tree/456060a26bbeb8fdf79326f224b6d99b8bcce736/hdri.
